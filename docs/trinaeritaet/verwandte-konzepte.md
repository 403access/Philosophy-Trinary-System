# Verwandte Konzepte

Die Trinärität ist kein isolierter Einfall. Sie hat Vorläufer und Nachbarn in
der Logik, Semiotik und Physik. Dieses Kapitel ordnet sie ein — und zeigt, was
jeweils fehlt.

## 1. Peirce: triadische Semiotik

**Charles Sanders Peirce** ist der bekannteste Denker einer fundamentalen
Trinärität. Seine Kategorien:

- **Erstheit** (*Firstness*): unmittelbare Qualität, Wahrnehmung.
- **Zweitheit** (*Secondness*): Widerstand, Faktizität, Dyade.
- **Drittheit** (*Thirdness*): Gesetzmäßigkeit, Vermittlung, Interpretation.

Im **semiotischen Dreieck** (Objekt – Zeichen – Interpretant) bleibt das
*dynamische Objekt* invariant, während verschiedene *Interpretanten*
unterschiedliche, aber gültige Relationen zum selben Objekt aufbauen.

| Peirce | Trinärität |
| --- | --- |
| Dynamisches Objekt | Kern $0$ |
| Interpretanten | Projektionen $\pm 1$ |
| Drittheit / Vermittlung | Invarianz-Bedingung |

**Was fehlt bei Peirce:** eine operative Admissibilitätsbedingung. Peirce sagt
nicht, wann ein Interpretant den Gegenstand *verfälscht*.

## 2. Supervaluationismus

**Bas van Fraassen** und **Kit Fine** beschreiben eine Semantik, in der eine
zugrundeliegende Realität unter verschiedenen Perspektiven unterschiedlich
bewertet wird, ohne dass die Wahrheit der Basis verloren geht:

- Es gibt eine objektive Basis.
- Es gibt mehrere zulässige **Präzisierungen** (*precisifications*).
- Eine Aussage ist **super-wahr**, wenn sie über alle zulässigen
  Präzisierungen hinweg gilt.

$$
\text{SuperTrue}(\varphi) \;:\Longleftrightarrow\; \forall p \in \mathcal{P}_{\text{adm}} : p \models \varphi
$$

Das ist das exakte Gegenstück zur Admissibilitätsbedingung: *„Wahrnehmungen
bleiben wahr, sofern sie die grundlegende Wahrheit nicht verändern.“*

**Was fehlt:** Der Supervaluationismus behandelt Vagheit, nicht Perspektivität.
Er hat keine Theorie der *Valenz* (gut/schlecht).

## 3. Relationaler Realismus (Rovelli)

**Carlo Rovelli** (*Relational Quantum Mechanics*) behauptet, dass es keinen
absoluten Beobachterzustand gibt, sondern nur Relationen zwischen Systemen:

- Ein System hat einen zugrundeliegenden Zustand (Hamilton-Operator,
  Invariante).
- Zwei Beobachter können scheinbar gegensätzliche Messwerte ($+1/-1$) erhalten.
- Beide Messungen sind *lokal* wahr, solange sie die Erhaltungsgrößen des
  Gesamtsystems nicht verletzen.

**Was fehlt:** RQM ist eine physikalische Theorie, keine philosophische Logik.
Die Übertragung auf Normativität ist eine Analogie, kein Beweis.

## 4. Bilateralismus

**Ian Rumfitt** und **Heinrich Wansing** trennen strikt zwischen:

- **Geltung** (*assertion*) — ontologische Ebene,
- **Akzeptanz/Ablehnung** (*acceptance/rejection*) — epistemisch-evaluative
  Ebene.

Das ergibt ein **$1+2$-System**: einen Kern und zwei Bewertungsrichtungen.
Genau die Struktur, die die Trinärität beschreibt.

| Bilateralismus | Trinärität |
| --- | --- |
| Assertion | Kern $0$ |
| Akzeptanz | $+1$ |
| Ablehnung | $-1$ |
| Konsistenzbedingung | Invarianz |

**Was fehlt:** Der Bilateralismus ist eine *proof-theoretische* Position. Er
sagt nicht, wie man Perspektiven auf einen gemeinsamen Weltkern modelliert.

## 5. Mehrwertige Logiken

**Łukasiewicz** ($\mathbf{L}_3$) und **Kleene** ($\mathbf{K}_3$) führen einen
dritten Wahrheitswert ein:

| System | Werte | Bedeutung von $\tfrac12$ / $u$ |
| --- | --- | --- |
| Łukasiewicz | $\{0,\tfrac12,1\}$ | „halb wahr“ |
| Kleene | $\{0,u,1\}$ | „unbestimmt“ |

Die Trinärität unterscheidet sich fundamental:

- $0$ ist **kein** mittlerer Wahrheitsgrad, sondern ein **ausgezeichnetes
  Zentrum**.
- Die Pole sind **keine** Wahrheitswerte, sondern **Perspektiven**.
- Die Gültigkeit ist **nicht** statisch (Wahrheitstabelle), sondern
  **invarianzabhängig**.

## 6. Parakonsistente Logik

**Graham Priest** und andere erlauben Widersprüche, ohne dass das System
explodiert (*dialetheism*). Ein Satz kann zugleich wahr und falsch sein.

Die Trinärität ist **nicht** parakonsistent im engen Sinn. Sie behauptet nicht,
dass $A \land \neg A$ wahr sein kann. Sie behauptet, dass zwei *Bewertungen*
desselben Fakts koexistieren können, ohne dass ein Widerspruch entsteht — weil
sie auf einer anderen Ebene liegen.
